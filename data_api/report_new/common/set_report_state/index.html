    Changing report status

    Changing the report state > State change
    Method set.report_state
    Description Change report status
    Available to Agent, Client
    Necessary components for working with the method Data API for configuration
    Method weight 1 point

    Request parameters

    method is specified
    Name Type Required Valid values Description
    access_token string yes Authentication session key
    user_id number no Unique user identifier of the agent client on behalf of which the request is made
    Is required for the agent
    To obtain a list of client users, you must use the method "get.customer_users"
    report_id number yes User report unique identifier. To get a list of user reports, you must use the "get.reports_list"
    Parameters of the transmitted report state
    state object yes Parameters of the transmitted report state
    limit number yes You cannot request more than 200 lines. Number of records to return. Default 50.
    offset number yes Shift - determines from which record number to return limit records. Default 0.
    date_from iso8601 yes Start date of main sample (limit 366 days)
    date_till iso8601 yes End date of the main sample
    compared_date_from iso8601 no Start date of the compared sample (limit 366 days).
    compared_date_till iso8601 depends on parameters End date of the compared sample.
    Required if compared_date_from
    perspective_window number yes You can set a period from 1 to 180 days from session to request Number of days from the session to the request in which the session request is attributed.
    dimensions array depends on parameters List of measurements used. For an available list of dimensions, see "Getting dimension nesting". The order affects the construction of the tree.
    Required for `report_type` = `ad_analytics`
    columns array yes List of columns used. For the available list of columns, see "Getting a list of columns" . Order influences report construction
    Filters applied in the report.
    filter object no It is permissible to use no more than 2 уровней nesting. See examples below Filters applied in the report. The construction logic is similar to "Filtering criteria"
    filters array yes An expression that can contain both simple filters and a filter tree
    field string The field of the entity to which filtering will be applied (the list is predefined for the method
    operator enum Filtering operator. A list of all operators can be obtained in the section "Filtering operators"
    value string Value for the filtering operator. Optional field; if it is missing, it is considered empty.
    Quick filters used in the report
    rapid_filter object no It is permissible to use no more than 2 уровней nesting. See examples below Quick filters used in the report. The construction logic is similar to "Filtering criteria"
    filters array yes An expression that can contain both simple filters and a filter tree
    field string The field of the entity to which filtering will be applied (the list is predefined for the method
    operator enum Filtering operator. A list of all operators can be obtained in the section "Filtering operators"
    value string Value for the filtering operator. Optional field; if it is missing, it is considered empty.
    Filters applied to columns
    columns_filter object no It is permissible to use no more than 2 уровней nesting. See examples below Filters applied to columns. The construction logic is similar to "Filtering criteria"
    filters array yes An expression can contain both simple filters and a filter tree.
    field string The field of the entity to which filtering will be applied (the list is predefined for the method
    operator enum Filtering operator. A list of all operators can be obtained in the section "Filtering operators"
    value string Value for the filtering operator. Optional field; if it is missing, it is considered empty.
    Sorting used in the report
    sort array no The sorting used in the report. The construction logic is similar to "Data sorting"
    Column options
    column_params object no List of columns with parameters.
    field object yes Mnemonic or identifier of the column whose parameters have been changed
    widths number yes Column width. Set in px.
