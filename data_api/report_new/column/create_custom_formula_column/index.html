    Create a custom column based on a formula

    Create a custom column based on a formula > Create a custom column based on a formula
    Method create.custom_formula_column
    Description Create a custom column based on a formula
    Available to Agent, Client
    Necessary components for working with the method Data API for configuration
    Method weight 1 point

    Request parameters

    method
    Name Type Required Valid values Description
    access_token string yes Authentication session key
    user_id number no Unique user identifier of the agent client on behalf of which the request is made
    Is required for the agent
    To obtain a list of client users, you must use the ["get.customer_users"](../../partner/get_customer_users.md) method
    report_type enum yes
    • ad_analytics
    • deals_analytics
    • chats
    		 User report type. To obtain a list of user reports, you must use the ["get.reports_list"](../get_reports_list)
    name string yes Column name
    description string no Column description
    data_type enum yes integer, float, currency, percentage, time Data format
    Calculated column formula
    formula array yes Formula for calculating a column. Order is important
    element_type enum yes
  1. column - Column identifier, only columns with type=metric can be passed. The list of columns can be obtained using the method "getobj.columns_tree"
  2. constant - numeric value, floating point format
  3. operator - arithmetic operations for the calculated expression. Can take values = +,-,\*,/
  4. priority - priority of the calculated expression. Can take values = (,)
    		5. Type of elements that will be used in the formula
    value string yes
  5. If element_type = column - it is possible to pass only column identifiers with type = metric. The list of columns can be obtained using the method "getobj.columns_tree"
  6. If element_type = constant - then you can only pass a floating point number number or an integer. Can be either positive or negative
  7. If element_type = operator - you can specify only arithmetic operations for the calculated expression. Can take values +,-,\*,/
  8. If element_type = priority - you can specify the values value = (,)
    		9. Column ID, value, arithmetic operation, priority that will participate in the formula

    Formula requirements

  9. + Arithmetic sum operation. You cannot put the first and last element in formula
  10. - Arithmetic subtraction operation. You cannot put the first and last element in formula
  11. \* Arithmetic multiplication operation. You cannot put the first and last element in formula
  12. / Arithmetic division operation. You cannot put the first and last element in formula
  13. (,) Symbols for prioritizing the execution of operations in formula. You cannot start a formula with ) and you cannot use ( at the end
  14. You cannot use element_type : operator more than 1 time in a row. Those. you cannot make combinations like // or \*\* or -/
  15. You cannot use element_type : constant or column with element_type : priority in a row without specifying an arithmetic operation. Those. you cannot make combinations like 11( or сс_1( or )сс_1
  16. You cannot use element_type : constant more than 1 time in a row.
  17.
