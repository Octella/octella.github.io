    Create a custom column based on a metric

    Create a custom column based on a metric > Create a custom column based on a metric
    Method create.custom_metric_column
    Description Create a custom column based on a metric
    Available to Agent, Client
    Necessary components for working with the method Data API for configuration
    Method weight 1 point

    Request parameters

    method method method will be substituted method
    Name Type Required Valid values Description
    access_token string yes Authentication session key
    user_id number no Unique user identifier of the agent client on behalf of which the request is made
    Is required for the agent
    To obtain a list of client users, you must use the ["get.customer_users"](../../partner/get_customer_users.md) method
    report_type enum yes
    • ad_analytics
    • deals_analytics
    • chats
    		 User report type. To obtain a list of user reports, you must use the ["get.reports_list"](../get_reports_list)
    name string yes Column name
    description string no Column description
    Parameters and conditions of the metric used
    metric object no Metric used in the column.
    id enum yes Unique metric mnemonic. To get a list of metrics you must use the ["get.metrics"](../get_metrics)
    aggregate enum yes The aggregate used for the metric. To obtain a list of available aggregates, you must use the ["get.metrics"](../get_metrics)
    has_percentage boolean no Whether the share calculation is used. If not specified, false
    multichannel_model enum no The multichannel analysis method used. To get a list of multichannel analysis methods, you must use the ["get.metrics"](../get_metrics)
    Filtering conditions imposed on the metric.
    filter object no It is permissible to use no more than 2 уровней nesting. See examples below Filtering conditions imposed on the metric. To get a list of available filtering conditions, see section ["Getting a list of available filtering conditions for a metric"](../get_metric_filters)
    filters array yes An expression that can contain both simple filters and a filter tree
    field string The field of the entity to which filtering will be applied (the list is predefined for the method
    operator enum Filtering operator. A list of all operators can be obtained in the section ["Filtering Operators"](../index.md#_filterOperators)
    value string Value for the filtering operator. Optional field; if it is missing, it is considered empty.

    JSON request structure```json

    { "jsonrpc": "2.0", "id": "number", "method": "create.custom_metric_column", "params": { "access_token": "string", "user_id": "number", "report_type": "enum", "name": "string", "description": "string", "metric": { "id": "enum", "aggregate": "enum", "has_percentage": "boolean", "multichannel_model": "enum", "filter": { "filters":[ { "field":"string", "operator":"enum", "value":"string" } ], "condition":"enum"
    } }
    } }

    { "jsonrpc": "2.0", "id": "number", "method": "create.custom_metric_column", "params": { "access_token": "2fRN4g217ef938dbf1e336d0..................................", "report_type": "ad_analytics", "name": "Звонки, количество", "description": "Создан столбец для примера", "metric": { "id": "calls", "aggregate": "count", "has_percentage": "boolean", "multichannel_model": "assisted_conversions", "filter": { "filters":[ { "filters":[ { "field":"utm_source", "operator":"=", "value":"yandex" }, { "field":"utm_source", "operator":"=", "value":"google" } ], "condition":"or" }, { "field":"utm_medium", "operator":"=", "value":"google" } ], "condition":"and" } } } }
