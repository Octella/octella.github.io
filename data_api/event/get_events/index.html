    Getting a list of events

    Method get.events
    Description Getting a list of all events
    Available to Agent, Client

    Request parameters

    Title Type Required Description
    access_token string yes Authentication session key
    user_id number no Unique user identifier of the client agent on behalf of which the request is made
    Is required for the agent
    To obtain a list of client users, you must use the method "get.customer_users"
    limit number no Number of records returned. See section "Paging"
    offset number no Shift determines from which record number to return "limit" records. Default is "0". See section "Paging"
    filter object no See section "Filtering criteria"
    fields array no See section "View of returned data"
    sort array no See section "Sorting data"

    Response parameters

    Name Type Valid values Filtering Sorting Description
    id number yes yes Unique event identifier
    name string yes yes Event name
    description string yes yes Event description
    site_id number yes yes Unique site identifier
    site_domain_name string yes yes Site address on the Internet. Without specifying the protocol - "http://" or "https://"
    type enum
    • comagic - System event. Cannot be deleted
    • track_event - Custom event. The settings use the fields category, action, action, value.
    • ppc_goal - Integrated goals of Yandex.Metrica and Google Analytics. Always have the flag is_goal = true, the fields engine, ext_id, goal_name are filled in.
    • link - Follow the link. The fields used are url, which stores a regular expression or tracking link.
    • time_on_site - Time on the site. The fields value are used, which stores the value of the tracked time at which the event is triggered in the format hh:mm:ss.
    • time_on_page - Time on a specific page of the site. The fields used are value, which stores the value of the tracked time at which the event is triggered in the format hh:mm:ss and url, which stores the tracked page of the site.
    • click - Click on the object. The fields used are value, which stores the value of the tracked element, and url, which stores the tracked page of the site. If url is not specified, then all pages are tracked.
    • scroll - Scrolling actions. The value fields are used, which stores the scroll type (comagic_scroll_start, comagic_scroll_end) or the tracked element to which the scroll occurs and url, in which the site page being tracked is stored.
    • segment - Entering a segment. The segment_id fields are used, which stores the identifier of the segment upon entry into which the event is triggered.
    		 yes yes Event types
    category string yes yes Tracked event category of type track_event
    action string yes yes Tracked event action of type track_event
    label string yes yes Tracked event label of type track_event
    value string yes yes Value of tracked event of type track_event or time for event type time_on_site,time_on_page or tracked element for event type click, scroll
    url string yes yes URL of the site page associated with the custom event type
    segment_id number yes yes Identifier of the segment when the event occurs. Used for events like segment
    is_goal boolean
    • true
    • false
    		 yes yes Whether the event is a target. For events like ppc_goal always true
    goal_name string yes yesName of the target if the event has the flag is_goal = true
    engine enum
    • yandex.metrika
    • google.analytics
    		 yes yes An external analytical system that is the source of the goal. For events like ppc_goal
    ext_id string yes yes External target identifier from an external system. For events like ppc_goal
    is_active boolean
    • true
    • false
    		 yes yes Whether the collection of this goal from an external analytical system is enabled. For events like ppc_goal
    ga_category string yes yes Category for the event sent to Google Analytics
    ga_action string yes yes Action for the transmitted event in Google Analytics
    ga_label string yes yes Label for the transmitted event in Google Analytics
    ga_value string yes yes Value for the event sent to Google Analytics
    ym_goal_id string yes yes Yandex Metrics goal ID
